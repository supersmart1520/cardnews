# 아이딜리 카드뉴스 편집기 — 사용 설명서

인스타그램에 올리는 **카드뉴스 3장**을 만드는 도구예요.
설치할 것도 없고, 가입할 것도 없어요. **파일 하나만 열면 끝**이에요.

---

## 이게 뭐예요?

카드뉴스는 인스타그램에서 옆으로 넘겨 보는 그림들이에요.
이 편집기는 그 그림 3장을 만들어 줘요.

- **첫장** — 사람들이 처음 보는 표지예요. 큰 글씨로 눈길을 끌어요.
- **중간장** — 하고 싶은 이야기를 자세히 적는 곳이에요.
- **마지막장** — 마무리 인사와 내 계정 이름을 넣는 곳이에요.

만든 그림은 **1080 × 1350** 크기로 저장돼요. 인스타그램에 딱 맞는 크기예요.

---

## 시작하기

1. `index.html` 파일을 찾아요.
2. 두 번 클릭해요.
3. 인터넷 창(크롬 같은 것)이 열리면서 편집기가 나와요.

끝이에요. 정말 이게 다예요.

> **한 가지만 기억해요:** 인터넷이 연결돼 있어야 글씨체가 예쁘게 나와요.
> 인터넷이 끊기면 글씨 모양이 이상해질 수 있어요.

---

## 화면 구경하기

화면이 **왼쪽**과 **오른쪽**으로 나뉘어 있어요.

| 어디 | 뭐 하는 곳 |
|------|-----------|
| **왼쪽** | 내용을 고치는 곳. 버튼이랑 글자 넣는 칸이 있어요. |
| **오른쪽** | 완성된 모습을 미리 보는 곳. 진짜 그림이 여기 나와요. |

**왼쪽에서 고치면 오른쪽이 바로 바뀌어요.** 저장 버튼 안 눌러도 돼요.

---

## 만드는 순서

### 1단계 — 어떤 장을 고칠지 고르기

왼쪽 맨 위에 단추 3개가 있어요.

```
[ 첫장 ]  [ 중간장 ]  [ 마지막장 ]
```

고치고 싶은 걸 누르면, 오른쪽 미리보기도 그 장으로 바뀌어요.

### 2단계 — 색깔 고르기

**포인트 컬러**는 눈에 띄게 하고 싶은 글씨의 색이에요.

- 네모난 색 상자를 누르면 색을 고를 수 있어요.
- 옆 칸에 `#FF91AC` 같은 걸 직접 써도 돼요. (`#`으로 시작하고 글자 6개예요.)

이 색은 **3장 모두에 한꺼번에** 적용돼요. 하나만 고르면 돼요.

### 3단계 — 배경 사진 넣기

**"클릭해서 이미지 업로드"** 라고 쓰인 네모를 눌러요.
내 컴퓨터에서 사진을 고르면 배경으로 깔려요.

사진이 마음에 안 드는 위치에 있으면, 아래 막대기 3개를 움직여요.

| 막대기 | 하는 일 |
|--------|---------|
| **가로 위치** | 사진을 왼쪽 ↔ 오른쪽으로 밀어요 |
| **세로 위치** | 사진을 위 ↕ 아래로 밀어요 |
| **확대** | 사진을 크게 키워요 |

> 배경 사진은 **장마다 따로** 넣어야 해요. 첫장 사진이 중간장에 자동으로 들어가지 않아요.

### 4단계 — 글자 쓰기

글자는 **두 가지 방법**으로 고칠 수 있어요. 편한 걸로 하면 돼요.

**방법 1 — 왼쪽 칸에 쓰기**
왼쪽 "텍스트" 아래에 있는 네모 칸에 쓰면 돼요.

**방법 2 — 오른쪽 그림에 바로 쓰기**
오른쪽 미리보기의 글자를 마우스로 클릭하면 커서가 깜빡여요. 거기에 바로 쓰면 돼요.

두 곳은 서로 연결돼 있어서, 한쪽을 고치면 다른 쪽도 같이 바뀌어요.

**줄을 바꾸고 싶으면** 왼쪽 칸에서 `Enter` 키를 누르면 돼요.

## 각 장에 뭘 쓰면 좋을까요?

### 첫장 (표지)

| 칸 | 어떤 내용을 쓰나요 | 예시 |
|----|-------------------|------|
| 소제목 | 작게 들어가는 설명 | `여름, 베이징 여행 후기` |
| 강조 문구 | 색깔로 강조되는 말 | `중국 여행사` |
| 메인 문구 1 | 제목 첫째 줄 | `꼭 먹어야 하는` |
| 메인 문구 2 | 제목 둘째 줄 | `현지 음식 추천` |

### 중간장 (본문)

| 칸 | 어떤 내용을 쓰나요 |
|----|-------------------|
| 계정 핸들 | 오른쪽 위에 작게 들어가는 내 인스타 이름 |
| 강조 헤딩 | 색깔로 강조되는 소제목 |
| 본문 1 | 설명하고 싶은 이야기 |
| 본문 2 | 이어지는 이야기 |

### 마지막장 (마무리)

| 칸 | 어떤 내용을 쓰나요 |
|----|-------------------|
| 중앙 문구 | 가운데 들어가는 마무리 인사 |
| 버튼 텍스트 | 알약 모양 단추 안에 들어가는 내 계정 이름 |

## 저장하기 (제일 중요해요!)

### 먼저 크기를 골라요

**"저장 크기"** 에서 하나 고르면 돼요.

| 고르는 것 | 언제 쓰나요 |
|-----------|------------|
| **1080 × 1350** | 그냥 인스타에 올릴 때. **이걸로 고르면 돼요.** |
| 2160 × 2700 | 더 또렷하게 하고 싶을 때 |
| 3240 × 4050 | 아주 크게 뽑고 싶을 때 |

크게 고르면 저장이 더 오래 걸리고 파일도 무거워져요.

### 그다음 단추를 눌러요

단추가 두 개 있어요.

**`현재 장 PNG 다운로드`**
지금 보고 있는 **한 장만** 저장해요. 그림 파일(PNG) 하나가 나와요.

**`전체 3장 한 번에 다운로드 (ZIP)`**
**3장을 몽땅** 저장해요. **딱 한 번만 누르면 돼요.**
`.zip` 이라는 상자 파일 하나가 내려와요. 그 안에 그림 3장이 들어 있어요.

> **zip 파일이 뭐예요?**
> 그림 여러 장을 담은 **상자**라고 생각하면 돼요.
> 내려받은 zip 파일을 두 번 클릭하면 상자가 열리면서 그림 3장이 나와요.
> (윈도우는 마우스 오른쪽 → "압축 풀기", 맥은 그냥 두 번 클릭하면 돼요.)

단추를 누르면 아래에 **"내보내는 중… (1/3)"** 같은 글씨가 나와요.
**"저장 완료"** 라고 뜰 때까지 기다려요. 몇 초 걸릴 수 있어요.

---

## 잘 안 될 때

**저장 단추를 눌렀는데 아무 일도 안 일어나요**
아래 글씨를 봐요. "내보내는 중…" 이면 아직 만드는 중이에요. 조금만 기다려요.

**글씨가 이상하게 겹쳐 보여요**
인터넷 연결을 확인해 봐요. 글씨체를 인터넷에서 받아오기 때문이에요.
연결한 뒤에 새로고침(F5) 하고 다시 해 봐요.

**"저장 실패" 라고 나와요**
1. 새로고침(F5) 을 하고 다시 해 봐요.
2. 저장 크기를 **1080 × 1350** 으로 낮춰서 해 봐요.
3. 크롬(Chrome) 이나 엣지(Edge) 로 열어 봐요.

**고친 게 다 사라졌어요**
이 편집기는 내용을 **저장해 두지 않아요.** 창을 닫으면 처음 상태로 돌아가요.
그래서 **다 만들면 꼭 그림으로 저장해 두세요.**

**배경 사진을 바꾸고 싶어요**
"클릭해서 이미지 업로드" 를 다시 눌러서 새 사진을 고르면 돼요.

---

## 꼭 기억할 것 3가지

1. 창을 닫으면 내용이 **사라져요.** 만들었으면 바로 저장해요.
2. 배경 사진은 **장마다 따로** 넣어요.
3. 3장을 다 받으려면 **`전체 3장 한 번에 다운로드 (ZIP)`** 를 **한 번만** 누르면 돼요.
