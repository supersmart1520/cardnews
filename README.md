# 아이딜리 카드뉴스 편집기

원고를 붙여 넣으면 AI가 장별로 나눠서 **인스타그램 카드뉴스(1080 × 1350)** 를 만들어 줍니다.
만든 뒤에는 글자를 눌러 바로 고칠 수 있고, 전체를 한 번에 내려받을 수 있어요.

---

## 어떻게 돌아가나요

```
원고 또는 사진 넣기
      ↓
AI가 내용을 읽고 장별로 나눔
      ↓
카드뉴스가 바로 만들어짐
      ↓
글자를 눌러 직접 고치기
      ↓
PNG 또는 ZIP 으로 저장
```

모든 단계가 **한 화면에** 있습니다. 탭을 왔다 갔다 할 필요가 없어요.

---

## 화면 보는 법

| 어디 | 무엇 |
|---|---|
| **왼쪽** | ① 내용 넣기 → ② 디자인 → ③ 카드 → AI 연결 → ④ 저장 |
| **오른쪽 위** | 만든 카드 전체. 누르면 그 장이 아래에 크게 나옵니다 |
| **오른쪽 아래** | 고르고 있는 장. **글자를 누르면 바로 고칠 수 있어요** |

---

## 쓰는 순서

### ① 내용 넣기

1. **원고** 칸에 글을 붙여 넣어요. 블로그 글, 메모, 안내문 무엇이든 괜찮아요.
2. 사진이 있으면 **이미지 추가하기** 로 올려요. (없어도 됩니다)
3. **업종**, **장수**, **목적** 을 고르고 **카드뉴스 만들기** 를 눌러요.

> **AI는 원고에 없는 사실을 지어내지 않습니다.**
> 날짜·가격·전화번호처럼 원고에서 확인할 수 없는 정보는 **비워 두고**,
> "무엇이 필요한지" 를 노란 상자에 적어 줍니다. 그 부분만 직접 채우면 돼요.

### ② 디자인

- **포인트 컬러** — 강조 글자·테두리·라벨 색.
  평소에는 지금 색 하나만 동그랗게 보이고, **색 고르기**를 누르면 36가지가 펼쳐집니다.
  원하는 색이 없으면 아래 칸에 `#RRGGBB` 로 직접 넣어도 됩니다.
- **어두운 색** — 라벨 글자와 배경 색
- **상단 띠 문구** — 표지·마무리 장 맨 위에 들어가는 한 줄
- **로고** — 글자로 넣거나 이미지로 바꿀 수 있어요

### ③ 카드

카드 목록에서 **▲▼** 로 순서를 바꾸고, **⧉** 로 복제, **✕** 로 지웁니다.
아래 모양 중 하나를 누르면 새 장이 들어갑니다. 두 가지 묶음이 있어요.

**사진 배경형 (9종)** — 사진이 화면을 꽉 채우고 글자가 그 위에 얹힙니다.

| 모양 | 역할 | 언제 쓰나요 |
|---|---|---|
| 표지 | 표지 | 첫 장. 사진 위 큰 제목 |
| 본문·큰제목 | 본문 | 핵심을 한마디로 말할 때 |
| 본문·중제목 | 본문 | 제목이 길 때. 따옴표 강조 |
| 질문·답변 | 본문 | 궁금증을 풀어 줄 때 |
| 컬러블록 | 본문 | 사진이 주인공일 때 |
| 2분할 | 본문 | 사진 두 장을 묶어 보여줄 때 |
| 3분할+목록 | 표지 | 여러 공간·메뉴를 한눈에 |
| 정리 | 정리 | 핵심 세 가지를 다시 보여줄 때 |
| 마무리·명함 | 마무리 | 마지막 장. 연락처와 인사 |

**창 프레임형 (6종)** — 옛날 컴퓨터 창처럼 생긴 테두리 안에 내용이 들어갑니다.
사진은 '액자' 안에 들어가고, 바깥 테두리 색이 포인트 컬러를 따라갑니다.

| 모양 | 역할 | 언제 쓰나요 |
|---|---|---|
| 창·표지 | 표지 | 가운데 정렬 표지 |
| 창·표지(왼쪽) | 표지 | 제목 + 키워드 칩 + 사진 |
| 창·단계 | 본문 | 방법 01, 02처럼 순서가 있을 때 |
| 창·질문답변 | 본문 | Q/A + 사진 + 체크 목록 |
| 창·수치 | 본문 | 숫자 두 개를 나란히 보여줄 때 |
| 창·마무리 | 마무리 | 실적 수치 + 연락처 |

### 사진 넣기

**클릭해서 사진 올리기**로 넣고, 아래 세 가지로 맞춥니다.

- **가로 / 세로** 막대 — 사진을 좌우·위아래로 옮깁니다
- **확대** 막대 — 사진을 크게 키웁니다
- **오른쪽 그림에서 사진을 직접 끌어서** 옮길 수도 있어요

### ④ 저장

- **이 장만 PNG 저장** — 보고 있는 한 장
- **전체 한 번에 저장 (ZIP)** — 전부. **한 번만 누르면 됩니다**
- **작업 파일로 저장** — 글·사진·색을 통째로 보관. 나중에 열어서 이어서 고칠 수 있어요
- **같은 디자인으로 다시 만들기** — 모양과 색만 남기고 글을 비웁니다

## AI 연결 (관리자만)

API 키는 **서버에만** 있습니다. 쓰는 사람은 키를 입력할 필요도, 볼 일도 없어요.

관리자가 Vercel에서 한 번만 설정하면 됩니다.

1. [aistudio.google.com/apikey](https://aistudio.google.com/apikey) 에서 키 발급
2. Vercel → 이 프로젝트 → **Settings → Environment Variables**
3. 아래를 넣고 저장

| 이름 | 값 | 필수 |
|---|---|---|
| `GEMINI_API_KEY` | 발급받은 키 | 필수 |
| `GEMINI_TEXT_MODEL` | `gemini-3.8-flash` | 선택 (비우면 기본값) |

4. **Deployments → 맨 위 … → Redeploy**

> 모델 이름은 서버가 정합니다. 브라우저가 보낸 값은 쓰지 않아요.

> **모델 이름이 바뀌어도 알아서 돌아갑니다.**
> 구글이 옛 모델을 닫을 때 "앞으로는 ○○를 쓰라"고 알려 주는데,
> 서버가 그 안내를 읽고 새 모델로 한 번 더 시도합니다.
> 계속 실패하면 위 표의 `GEMINI_TEXT_MODEL` 에 안내받은 이름을 직접 넣으면 됩니다.

### AI가 하는 일

원고를 읽고 **장별 제목·본문으로 나누는 것**, 그리고 **올린 사진이 무엇인지 보고 알맞은 장에 넣는 것** 두 가지입니다.
배경 그림을 만들어 주지는 않습니다. 사진은 직접 올려서 쓰세요.

## 잘 안 될 때

| 나오는 말 | 어떻게 하나요 |
|---|---|
| AI 키가 서버에 설정되지 않았습니다 | 관리자가 Vercel 환경 변수에 키를 넣고 다시 배포해요 |
| 서버의 AI 키가 올바르지 않습니다 | 관리자가 키를 다시 확인해요 |
| AI 모델을 찾을 수 없습니다 | 관리자가 `GEMINI_TEXT_MODEL` 을 고쳐요 |
| 한도를 넘었습니다 | 잠시 뒤 다시 하거나 결제 상태를 확인해요 |
| 사진이 너무 큽니다 | 사진 수를 줄이거나 작은 사진을 써요 |
| 글자가 겹쳐 보여요 | 인터넷 연결 확인 후 새로고침(F5) |

**고친 게 사라졌어요** — 창을 닫으면 내용이 사라집니다.
다 만들었으면 **PNG 저장** 과 **작업 파일로 저장** 을 꼭 해 두세요.

---

## 꼭 기억할 것

1. 창을 닫으면 내용이 **사라집니다.** 저장은 꼭 해 두세요.
2. AI가 **비워 둔 칸**(날짜·가격 등)은 직접 채워야 합니다.
3. 전체를 받으려면 **전체 한 번에 저장 (ZIP)** 을 **한 번만** 누르면 됩니다.
