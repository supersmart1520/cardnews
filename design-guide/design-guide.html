03. 프레임 모티프 · 레트로 브라우저 창

모든 카드의 공통 뼈대. 바깥 블루 프레임 → 블랙 테두리 창 + 하드 그림자 → 타이틀바(점 3개) → 콘텐츠 + 우측 스크롤바.

▲
▼
  • 바깥 블루 프레임 — 16px 코발트 블루 외곽선(#0355FD)이 카드 전체를 감싼다.
  • 레트로 창 — 5px 블랙 테두리 + 오른쪽·아래 16px 하드 블랙 그림자(offset, blur 없음)로 입체감.
  • 타이틀바 — 패널 그레이 바 + 하단 블랙 라인, 오른쪽에 속이 빈 점 3개. 왼쪽에 작은 라벨(예: cardnews.exe) 선택.
  • 우측 스크롤바 — 세로 트랙 + 위/아래 삼각형 + 블랙 썸(thumb). 장식 전용.
  • 여백 — 콘텐츠 영역은 상하 64px·좌우 72px, 스크롤바를 피해 우측 여유.

06. 카드 역할별 레이아웃 6종

보통 6장 구성: 표지 → 도입 → 핵심정보 → 리스트 → 비교·사례 → 마무리 CTA. 제공 템플릿은 ★표시.

01표지형 ★
큰 메인 타이틀 + 핵심 키워드 박스 + 부제(↳) + 로고 슬롯. 커서·픽셀로 포인트.
02도입/본문형 ★
도입 문단 + 중간 강조 문장 + 하단 큰 펀치라인. 키워드/밑줄 강조 활용.
03핵심정보형
소제목
검정 알약 소제목 + 한 가지 핵심 개념을 크게 설명. 아이콘 1개로 상징.
04리스트형 ★
번호(01·02…) + 아이콘 + 제목 + 설명을 반복. 2~4개 항목 정리에 최적.
05비교·사례형 ★
VS
A VS B 대비 또는 사례 리스트(기관/인용). 점선 구분 + 블루 뱃지.
06마무리 CTA형 ★
핵심 요약 한 줄 + 회색 박스 안 마무리 메시지/전망/행동 유도(CTA).

07. 내용 넣는 법

템플릿 HTML의 플레이스홀더 텍스트를 실제 문구로 바꾸면 완성됩니다.

  1. 원하는 역할의 템플릿 파일을 복사한다 (예: 표지는 template-01-cover.html)
  2. "~자리"로 표시된 플레이스홀더 텍스트를 실제 문구로 교체한다.
  3. 강조할 단어는 <span class="c-blue">(파란 키워드) / u-blue(밑줄) / k-box(박스)로 감싼다.
  4. 아이콘/로고 슬롯에는 SVG·이미지를 넣고, 불필요한 장식은 지워도 된다.
  5. Playwright로 1080×1350px(scale 2) PNG 렌더 → 인스타 업로드.
